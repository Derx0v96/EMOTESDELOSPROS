# EMOTESDELOSPROS

Este repositorio ya incluye un pack sencillo de emotes de Twitch para ver en navegador.

## Archivos principales

- `index.html` — página principal
- `styles.css` — estilos del sitio
- `script.js` — render de emotes
- `assets/emotes/` — assets SVG de ejemplo para los emotes

## Emotes incluidos

- KEKW
- MonkaS
- WeirdChamp

## Cómo abrirlo

Abre `index.html` en tu navegador o usá un servidor local simple como:

```bash
python3 -m http.server 8000
```

Luego entra a:

```text
http://localhost:8000/
```

Si querés, después puedo cambiar estos SVG por imágenes reales o dejarlo listo como proyecto de React/Next.
